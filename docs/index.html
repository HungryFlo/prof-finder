五步完成导师匹配

与应用内工作台一致：沉淀经历 → 建立画像 → 添加教授 → 运行匹配 → 生成邮件。

STEP 1

沉淀经历

在「信息池」写下学术相关经历碎片，经脑暴、聚类、细化后取材生成文书片段，形成可复用的素材库；可创建多个独立池。

STEP 2

建立画像

上传 Markdown / LaTeX / 文本简历，可选绑定信息池；LLM 解析研究方向与经历，支持 AI 对话继续打磨画像。匹配前请至少激活一个画像。

STEP 3

添加教授

Google Scholar、DBLP、院校批量爬取或手动录入；可关联外部档案合并 Scholar 与 DBLP 数据。后台任务抓取论文、引用与科研画像。

STEP 4

智能匹配

首次从 ModelScope 下载 Qwen3-Embedding（约 1.2 GB）后本地运行，对激活画像与教授科研画像做语义相似度排序，并给出匹配理由。

STEP 5

生成套磁信

用你自选的 LLM API（OpenAI 兼容或 Anthropic）结合画像与信息池细化经历生成个性化中英文联络信；支持编辑与复制，发送前须人工审阅。

核心能力

从经历沉淀到套磁联络，覆盖申请准备的完整工作流。

信息池

脑暴线索、聚类整理、细化过程细节，再取材生成个人陈述 / 研究计划等文书片段，并可应用到学生画像。

脑暴 → 聚类 → 细化 → 文书

语义匹配引擎

Qwen3-Embedding 本地运行，将学生画像与教授科研画像做深度语义比对，输出相似度排名和匹配理由。

本地优先

简历、教授与匹配结果保存在本机 SQLite；便携版自选数据目录，不上传云端。

多源导入

Google Scholar、DBLP、院校批量与手动录入；可关联外部档案合并多源数据。

智能套磁信

结合画像与信息池细化经历生成个性化邮件；支持 DeepSeek、OpenAI、Anthropic 等自选 API。

画像 AI 对话

在画像详情用对话迭代打磨材料；爬取与匹配走 Huey 后台任务，SSE 实时进度，不阻塞操作。
