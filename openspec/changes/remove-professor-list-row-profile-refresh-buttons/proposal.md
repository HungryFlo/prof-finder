# Change: 移除教授列表行内「画像」「更新」按钮

## Why

列表行内的单条「更新」与「画像」与表头的批量能力重复，界面拥挤；用户希望只通过批量入口触发同类操作，减少误触并保持列表操作区简洁。

## What Changes

- 教授列表表格「操作」列不再渲染逐行的「更新」「画像」按钮。
- 保留表头在有选中行时展示的「批量更新」「批量生成画像」及既有批量删除等能力。
- 单教授的刷新与科研画像生成仍可通过教授详情页等既有路径完成（不删除后端 API）。

## Impact

- Affected specs: `web-frontend`（教授管理页操作与场景描述）。
- Affected code: `frontend/src/views/professor/ProfessorListView.vue`（列定义与仅被行内按钮引用的处理函数，若实现阶段确认无其他引用可一并删除）。
